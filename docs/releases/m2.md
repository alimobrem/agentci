## What ships

AgentCI selects versioned suites from change impact and requirements, executes
command/pytest and optional Promptfoo/DeepEval or registered HTTP adapters,
aggregates repeated trials and compares exact base/head code under frozen baseline
assertions. Deleting or weakening a head suite cannot erase baseline regressions.
Missing/skipped execution, infrastructure errors and cancellation remain explicit.

A separate evaluator isolates reviewed commands from controller/App credentials.
GitHub receives advisory semantic and behavioral Checks. Agents read authenticated,
identity-bound comparison records and complete certified exports. This milestone
uses GitHub Checks, CLI and APIs; the first web dashboard is planned for M3.

## Released-build walkthrough

After installing the public package and following [the M2 guide](../m2-guide.md),
configure a repository-only App and keep private operator configuration outside Git:

```sh
agentci --version
agentci review --config /absolute/private/operator.json --pr 3
```

The demonstrated repository is the separately approved
`alimobrem/agentci-onboarding-demo`. The original App remains scoped to
`alimobrem/agentci`. This fixture uses two trials with a strict baseline expecting
`SAFE`; the head has weaker assertions. Changing the response to `UNSAFE` produced
[one regression and two critical failures](https://github.com/alimobrem/agentci-onboarding-demo/pull/3/checks?check_run_id=111599001903).
The baseline passed and the head failed both trials.

After repairing the response, an evaluator runner-identity mismatch produced an
explicit cancelled Check, not a passing result. Restoring the operator image and
requesting a fresh attempt on the identical head recovered. The anonymously
installed CLI's [new passing Check](https://github.com/alimobrem/agentci-onboarding-demo/pull/3/checks?check_run_id=111605200155)
was independently consumed by the installed client. The old failure's digest and
status remain unchanged. Authentication failure, wrong-head identity and certified
export completion were verified; all observed owned child containers were removed.

The failed/regressing executions used these same immutable published images and
package bytes. Their retained evidence was revalidated with the public client;
they are not represented as newly executed after public package download. Reusing
that evidence avoids recreating an already proven failure unnecessarily.

A neutral GitHub conclusion does not mean behavioral success: read the outcome
inside the Check or comparison. The temporary tunnel/shared local Docker daemon
is a development onboarding demonstration, not managed production hosting.
Hosted AgentCI self-review runs on GitHub independently of the laptop; its passing,
regressing and recovered PR evidence is retained separately.

## Limits and next phase

Docker is the approved M2 default; Podman adoption/security/stability remains
separately deferred. The optional engine retains node-forge 1.4.0 with a pinned
maintainer-owned patch and a visible HIGH version-based scanner finding. Statistical
intervals describe the observed sample, not universal model safety. Suite classes
integrate operator-supplied assertions; they do not supply every domain's quality
algorithm. Full tracing, policy enforcement, release coordination and production
feedback remain later milestones in the original control-plane plan.

See [the M2 retrospective](../retrospectives/m2.md) for measured bottlenecks and
concrete improvements, and [the phase/PR plan](../phase-pr-plan.md) for subsequent
scope. M3 begins only after final M2 closure and the user-facing demo.
