Model/behavioral evals and GitHub dogfood are not applicable to M0: no model calls,
behavioral runner or PR review is implemented. Those are future milestone gates.
The API is a loopback-only skeleton without persistence/authentication; do not
deploy it as a hosted product. JSON Schema validation does not establish evidence
truth, implement blocking policy, or guarantee immutability in storage.

M1 has not started. Temporal is the recommended M1 orchestration backend; its
deployment and integration still require implementation and verification.

Container images are not required by the M0 specification. Its API remains a
local development skeleton. When a milestone introduces deployable services,
the release must include applicable OCI images, runtime smoke tests, vulnerability
scan results and published immutable image digests. CLI packaging remains the npm
archive; it does not require a container image.
