## Existing boundaries that must precede expansion

`ReviewBinding` currently contains only model admission, backend origin and read token. `configSchema` is strict. Adding analysis/comparison IDs silently, choosing arbitrary latest evidence, or reusing a credential without demonstrating matching scope would cross this boundary. An expansion must define and validate explicit evidence IDs and full expected identities, authorize the same organization/repository/PR/base/head, enforce bounded reads and session revocation, and test cross-tenant, stale-head, changed-digest, missing evidence and interrupted reads before projection.

Analysis evidence and eval comparison APIs already exist; they do not establish the missing dashboard binding. Intent and disagreement require a specific retained source and read contract before UI implementation. No backend or API contract expansion is included in this local candidate.

## Acceptance still open

The 38-case production browser fixture corpus covers the bounded current view, retained history/export, transport truncation/trailing bytes, exact finding pin/digest/version chains, account changes, expiry during reads, fresh-session download checks, deadlines, revocation and redacted health probes. It does not establish real repeated/interrupted identity-provider login, failed-callback Back/Forward, interruption during an actual streamed browser file download, provider-backed reviewer behavior or deployed customer access. Those remain explicit requirements; local fixtures do not close the complete UI gate.

Sessions and pending login transactions are process-local. Restart invalidates both; multi-replica operation is unsupported without shared stores and acceptance. Local `/readyz` validates configuration/admission shape and identity only, not OIDC discovery, authentication or backend availability. Native UBI build/startup/shutdown, image UID 1001, OS/RPM/Node notice inventory, exact image scan and ARM64 execution remain unverified. The actual JavaScript runtime notice inventory still reports 22 unresolved declaration/notice items; verified descriptor associations are provenance evidence, not legal clearance.
